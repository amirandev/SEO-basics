## სლაიდი 3: როგორ ირჩევს AI Overviews წყაროებს?

Google AI Overviews **არ იყენებს** ჩვეულებრივ search ranking-ს. მისი შერჩევის მექანიზმი განსხვავებულია:

**1. Relevancy Score:**
- კონტენტი პირდაპირ პასუხობს მომხმარებლის კითხვას
- **ფრაგმენტის სიზუსტე** — AI ამოიღებს კონკრეტულ წინადადებას/აბზაცს

**2. Authority Signals (AI-სთვის):**
- **Sitelinks** — კარგი შიდა ლინკების სტრუქტურა
- **Schema.org** — Article, FAQPage, HowTo, Product
- **Entity Recognition** — Google-მა იცის, ვინ ხართ (Knowledge Graph)

**3. Content Freshness:**
- AI Overviews უპირატესობას ანიჭებს **ბოლო 6-12 თვის** კონტენტს
- **განახლებული სტატიები** უკეთესად მუშაობს

**4. Format Preference:**
- **Listicles** (სიები) > ჩვეულებრივი პარაგრაფები
- **ცხრილები** > ტექსტი (ტაბულური მონაცემები)
- **Q&A ფორმატი** > narrative text

## სლაიდი 4: Content Structure — AI-სთვის ოპტიმიზებული ფორმატები

**რა ფორმატებს ანიჭებს AI უპირატესობას:**

**1. Direct Answer (პირდაპირი პასუხი):**
```html
<!-- 🟢 AI გამოარჩევს: მკაფიო პასუხი კითხვაზე -->
<h2>What is Core Web Vitals?</h2>
<p>Core Web Vitals are three metrics — LCP, INP, and CLS — that measure user experience.</p>

<!-- 🔴 AI გაუჭირდება: არაპირდაპირი, მოცილებული პასუხი -->
```
AI-სთვის: **პირველი წინადადება = პასუხი**, შემდეგი = განმარტება

**2. Q&A ფორმატი:**
```html
<h2>Does page speed affect SEO?</h2>
<p>Yes, page speed has been a Google ranking factor since 2018...</p>

<h2>How can I improve LCP?</h2>
<p>To improve LCP, preload your hero image and use fetchpriority="high"...</p>
```

**3. Definition List (`<dl>`):**
```html
<dl>
  <dt>LCP</dt>
  <dd>Largest Contentful Paint — measures loading speed. Target: ≤2.5s</dd>
  <dt>INP</dt>
  <dd>Interaction to Next Paint — measures interactivity. Target: ≤200ms</dd>
</dl>
```

## სლაიდი 5: Entity Density & Semantic Richness

**Entity Density** — რამდენად "მდიდარია" თქვენი კონტენტი სემანტიკური ერთეულებით.

```html
<!-- 🔴 Low entity density: -->
<p>Our product is very good and works well. Many customers like it.</p>

<!-- 🟢 High entity density (AI-სთვის გასაგები): -->
<p>The <strong>MacBook Pro M4</strong> features a <strong>14-inch Liquid Retina XDR display</strong>, 
<strong>M4 Pro chip with 14-core CPU</strong>, and <strong>24GB unified memory</strong>. 
Battery life reaches <strong>22 hours</strong>.</p>
```

**როგორ გავზარდოთ entity density:**
1. **ნუ იტყვით "it"** — ყოველთვის გამოიყენეთ კონკრეტული სახელი
2. **Numbers & data** — AI მოიხმობს ფაქტებს (22 hours, 14-core, 24GB)
3. **Synonyms & variations** — NLP-სთვის (SEO optimization, search engine optimization)

**Internal Linking Entity Signals:**
```html
<!-- 🟢 Entity linking — AI ხვდება ურთიერთობას -->
<p>Learn more about <a href="/lcp-optimization">LCP optimization techniques</a> 
in our <a href="/core-web-vitals-guide">Core Web Vitals guide</a>.</p>
```

## სლაიდი 6: Schema Markup AI-სთვის — რეალური გავლენა

**რომელი schema ტიპები მოქმედებს AI Overviews-ზე:**

**1. FAQPage Schema:**
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "What is LCP in Core Web Vitals?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "LCP (Largest Contentful Paint) measures loading performance. Good score is ≤2.5 seconds."
    }
  }]
}
```
- ✅ AI Overviews **პირდაპირ იყენებს** FAQ schema-ს პასუხებისთვის
- ⚠️ Google-ის Helpful Content Update-ის შემდეგ FAQ snippets **შემცირდა**

**2. HowTo Schema:**
```json
{
  "@type": "HowTo",
  "name": "How to Improve LCP",
  "step": [
    { "@type": "HowToStep", "name": "Preload hero image", "text": "Add link rel=preload..." },
    { "@type": "HowToStep", "name": "Optimize server TTFB", "text": "Use CDN and caching..." }
  ]
}
```

**3. Article Schema (Enhanced):**
```json
{
  "@type": "Article",
  "headline": "Core Web Vitals Optimization Guide",
  "datePublished": "2026-05-15",
  "dateModified": "2026-07-20",
  "author": {
    "@type": "Person",
    "name": "John Doe",
    "sameAs": "https://linkedin.com/in/johndoe"
```

## სლაიდი 7: Content Freshness & AI Overviews

AI Overviews **მნიშვნელოვნად** უპირატესობას ანიჭებს ახალ კონტენტს.

**Freshness Strategy:**

**1. Content Refresh — განაახლეთ ძველი სტატიები:**
- შეცვალეთ `dateModified` schema-ში
- დაამატეთ ახალი მონაცემები (2026 stats, new examples)
- AI-მ "ნახოს", რომ გვერდი განახლებულია

**2. "Last Updated" ვიზუალური მითითება:**
```html
<p class="last-updated">Last updated: July 2026 • Originally published: January 2025</p>
```

**3. Evergreen + Trending Balance:**
- **80% Evergreen** — მარადიული თემები (რა არის X, როგორ გავაკეთოთ Y)
- **20% Trending** — ახალი ამბები, 2026 წლის მონაცემები

**4. AI Crawling Frequency:**
- GPTBot, ClaudeBot, Google-Extended **ხშირად** აკრალავს განახლებულ გვერდებს
- `Last-Modified` HTTP header — მნიშვნელოვანია AI-სთვის

## სლაიდი 8: AI Citation Patterns — როგორ და რატომ ციტირებს AI

**AI ციტირების 3 ტიპი:**

**1. Direct Citation (Inline):**
> "LCP should be under 2.5 seconds" [source: example.com]
- AI **ზუსტად** იმეორებს თქვენს ფრაზას
- მოითხოვს: მკაფიო, ფაქტობრივ განცხადებას

**2. Summarized Citation:**
> According to multiple sources, Core Web Vitals are important for SEO
- AI **აჯამებს** თქვენს კონტენტს, მაგრამ გიციტირებთ
- მოითხოვს: **სრულ, ავტორიტეტულ სტატიას**

**3. Uncited Reference:**
> Core Web Vitals include LCP, INP, and CLS
- AI იყენებს ინფორმაციას, **მაგრამ არ გიციტირებთ**
- მიზეზი: ინფორმაცია "common knowledge"-ად ითვლება

**როგორ გავზარდოთ ციტირების შანსი:**
```html
<!-- 🟢 Citation-friendly: unique data point -->
<p>According to Google's 2026 transparency report, <strong>73% of AI Overviews 
citations come from pages published within the last 12 months</strong>.</p>

<!-- 🔴 Non-citation: generic claim -->
<p>Fresh content is important for AI visibility.</p>
```

## სლაიდი 9: ChatGPT Search — Optimization

ChatGPT Search **განსხვავდება** Google AI Overviews-ისგან:

**1. HTML Structure Sensitivity:**
```html
<!-- 🔴 ChatGPT-ს გაუჭირდება: complex nested -->
<div class="content">
  <div class="wrapper"><div class="inner"><p>Answer</p></div></div>
</div>

<!-- 🟢 ChatGPT-friendly: clean, semantic -->
<article>
  <h2>Question</h2>
  <p>Direct answer here.</p>
</article>
```

**2. Source Attribution Priority:**
- **.edu, .gov** domains — მაღალი ავტორიტეტი ChatGPT-სთვის
- **Wikipedia-style citation** — ChatGPT მიჰყვება citation chain-ებს
- **Author byline** — `author` schema + author bio ზრდის ნდობას

**3. Code Blocks & Technical Content:**
- ChatGPT **უპირატესობას** ანიჭებს code blocks-ებს
```javascript
// 🟢 ChatGPT will quote this code
function calculateLCP() {
  // implementation
}
```

**4. Structured Lists:**
- ChatGPT **ამჯობინებს** `<ul>`/`<ol>` — უფრო ადვილად გარდაქმნის

## სლაიდი 10: Perplexity — Answer Engine Optimization

Perplexity-ის მთავარი განსხვავება: **inline citations** ყოველ წინადადებაში.

**Perplexity-ის წყაროს შერჩევა:**

**1. Fact Density — ფაქტების სიმჭიდროვე:**
```html
<!-- 🟢 Perplexity-friendly: multiple facts per paragraph -->
<p>The iPhone 16 Pro has a 6.3-inch OLED display with 120Hz ProMotion, 
powered by the A18 Pro chip with a 6-core GPU. 
It starts at $999 and offers up to 33 hours of video playback.</p>
```

**2. Data Sources — ციტირებადი მონაცემები:**
- **Numbers** — 33 hours, $999, 6.3-inch
- **Comparisons** — "30% faster than previous generation"
- **Statistics** — "according to a 2026 study..."

**3. Source Diversity — მრავალფეროვანი წყაროები:**
- Perplexity **აღნიშნავს**, რამდენი წყარო გამოიყენა
- ერთი სტატიის ნაცვლად — **თემატური ავტორიტეტი**
- **Multiple pages** from your site = უკეთესი შანსი

**4. No-BS Content:**
- Perplexity-სთვის **არასასურველია**: padding, fluff, introduction paragraphs
- **Direct value** from the first sentence

## სლაიდი 15: Content Pruning for AI — რა წაშალოთ

**AI-სთვის "მავნე" კონტენტი:**

AI robots (GPTBot, ClaudeBot) **კითხულობს მთელ საიტს**. თუ თქვენ გაქვთ დაბალი ხარისხის გვერდები, AI ამას ნახავს და **შეამცირებს** თქვენი საიტის ავტორიტეტს.

**Content Pruning — AI-სთვის:**

| ტიპი | გადაწყვეტილება | მიზეზი |
|------|----------------|--------|
| Thin content (<300 words) | წაშალეთ ან გააერთიანეთ | AI ჩათვლის "low value" |
| Duplicate content | Canonical URL ან წაშლა | AI აბნევს source attribution-ს |
| Outdated stats (2020-2022) | განაახლეთ | AI-ს Freshness სიგნალი |
| Orphan pages | Add internal links ან წაშალეთ | AI ვერ პოულობს კონტექსტს |
| Spammy/low-quality blog | **წაშალეთ** | GPTBot-ს ეს "აბინძურებს" თქვენს profile-ს |

**AI Content Audit — 6 თვეში ერთხელ:**
1. იპოვეთ 100+ გვერდიანი "dead weight"
2. წაშალეთ ან გაააერთიანეთ

## სლაიდი 16: E-E-A-T for AI — განსხვავებული წესები

**E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)** AI-სთვის:

**Experience (გამოცდილება):**
```html
<!-- 🟢 AI-მ იცის, რომ ეს პირადი გამოცდილებაა -->
<p>In our 5 years of SEO consulting, we've found that preloading the hero image 
improves LCP by an average of 0.8 seconds.</p>
```

**Expertise (ექსპერტიზა):**
- Author schema — `Person` + `sameAs` (LinkedIn, GitHub)
- **Author bio** — გვიჩვენებს, რომ ექსპერტი ხართ
- **Citations** — საკუთარი წყაროების მითითება

**Authoritativeness (ავტორიტეტი):**
- **Backlinks** — AI იყენებს backlink profile-ს, როგორც სიგნალს
- **Site reputation** — რას ამბობენ სხვები თქვენზე
- **Mentions** — unlinked mentions-იც კი მუშაობს

**Trustworthiness (სანდოობა):**
- **External citations** — თქვენი წყაროები უნდა იყოს სანდო
- **Date clarity** — `datePublished` + `dateModified`
- **Contact info** — `About` page, contact details

## სლაიდი 18: Prompt-Based Content Strategy

**Content Strategy for AI Prompts:**

AI მომხმარებლები სვამენ prompt-ებს. თუ თქვენი კონტენტი prompt-ზე "პასუხობს" — AI გამოგიყენებთ.

**Prompt Types to Target:**

**1. "What is X?" — Definition Prompts:**
```
User prompt: "What is Core Web Vitals?"
AI needs: Clear definition + key points
Your content: ზუსტად ეს — "LCP, INP, CLS..."
```

**2. "How to X?" — Tutorial Prompts:**
```
User prompt: "How to improve LCP?"
AI needs: Step-by-step instructions
Your content: Numbered list + code examples
```

**3. "X vs Y" — Comparison Prompts:**
```
User prompt: "React vs Next.js for SEO?"
AI needs: Comparison table + pros/cons
Your content: `<table>` + `✅/❌` format
```

**4. "Best X for Y" — Recommendation Prompts:**
```
User prompt: "Best tools for SEO in 2026?"
AI needs: Ranked list + key features
Your content: Listicle with pricing, features, pros/cons
```

## სლაიდი 20: AI-Blocking Strategy — როდის დაბლოკოთ

**ყველას არ სჭირდება AI visibility:**

**დაბლოკეთ AI (robots.txt), თუ:**
- თქვენი კონტენტი არის **paywalled/private**
- AI Overviews **აზიანებს** თქვენს business model-ს (e.g., news sites)
- ეშინიათ **copyright/plagiarism**-ის
- AI chatbots **ავრცელებს** არასწორ ინფორმაციას თქვენს შესახებ

**დაუშვით AI, თუ:**
- გსურთ **brand awareness** AI-ს მეშვეობით
- თქვენი კონტენტი **information-based** (blog, education, tutorials)
- AI Overviews **drive clicks** (e-commerce, tools, unique data)

**Selective Blocking:**
```text
# 🟢 Block AI training, allow search citation
User-agent: GPTBot
Disallow: /private/
Allow: /public/

User-agent: Google-Extended
Disallow: /private/

# Google Search bot — full access
User-agent: Googlebot
Allow: /
```
